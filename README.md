# What's this?
It's a Hackclub Terra project for week 2. Its name is DevBuddy and runs in your CLI, as the name suggests it's your own developer buddy that allows you to have todo lists, an ai coding assistant (subject to harsh rate limits) and a motivational quote each day. 

# usage
`python devbuddy.py [command]`
To get the commands available, use --help.

i do plan creating an .exe file in Releases

# privacy
all data is stored in a json file in the data folder and is never sent to my servers or stored on the web

# env variables
this needs to be available for the ai coding assistant to work:
